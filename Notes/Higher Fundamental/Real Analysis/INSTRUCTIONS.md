#Incio
A estrutura do texto reflete academisismo adjunto de uma voz gentil,
a qual continuamente quebra a quarta parede se cumunicando com o leitor diretamente.

#Estrutura
O livro é dividio em seções, sendo estas uma coleção de capitulos.
Antes de cada Seção, Capitulo ou Paragrafo importante deve haver uma sequencia de comentarios
superior ao texto - com // e terminado com uma cometario vazio - explicando a importancia do texto a seguir,
assim como a estrutura linguistica que será empregad apara atingir o objetivo
( argumentar, decrever o problema, incita algum sentimento ... )
